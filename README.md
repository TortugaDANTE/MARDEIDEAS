# Mar de Ideas

Repositorio del acuario interactivo **Mar de Ideas** para la Revista Jandiekua (UASLP / Agenda Ambiental).

## Versión actual
- **v8** — Peces a mitad de tamaño, con PNGs transparentes.

## Archivos
- `index.html` → versión completa (sube el archivo preparado desde el chat).
- `apps-script-mar-de-ideas.js` → webhook para guardar aportaciones en Google Sheets.
